# 🚗 Traffic Volume Prediction

Machine Learning application for predicting traffic volume
using historical traffic, weather and temporal features.

## 🚀 Live Demo

[▶ Open Traffic Prediction App]

## 📌 Problem Statement

Traffic volume varies based on time, weather, holidays
and other environmental factors.

This project builds a machine learning pipeline that
predicts traffic volume from these variables.
