# models/

Place your trained model `.pkl` files here:

- `FINAL_lgb_junction1.pkl`
- `FINAL_lgb_junction2.pkl`
- `FINAL_lgb_junction3.pkl`
- `FINAL_lgb_junction4.pkl`
- `FINAL_lightgbm_model.pkl`  (global fallback)

These are generated by `Data_Modeling_n_Model_evaluation_Sayed_Shoaib.ipynb`.

If your `.pkl` files are too large for GitHub (>50 MB each), consider:
- Using [Git LFS](https://git-lfs.github.com/)
- Hosting on [Hugging Face Hub](https://huggingface.co/) and downloading at runtime
